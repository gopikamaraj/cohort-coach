# Sample check papers (SAMPLE, no child data)

Made by `python scripts/paper_studio.py samples` from rules version 1, for a made-up class labelled "SAMPLE" with made-up class counts. No child, name or answer is in any file.

- `SAMPLE-A-pre-<layout>.pdf`: a pre-test (Form A) with 10 anchor and 5 adaptive items.
- `SAMPLE-B-post-<layout>.pdf`: its post-test twin (Form B): the same skills and level, new numbers.
- `...-key.pdf`: the answer key with the common wrong answer for each error, for hand marking.
- `....layout.json`: where every box is, in millimetres (answer boxes, roll number box, form letter, check code, corner marks).

Layouts: one language (`en`, `hi`, `ta`) or two, first language first (`en_hi`, `en_ta`, `hi_en`, `hi_ta`, `ta_en`, `ta_hi`). The Hindi and Tamil wording is waiting for a reader of each language. The answer key explains its header in plain words and says why item 6 has no wrong answers (it only checks that the child can take away at all).
