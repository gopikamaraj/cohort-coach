## Screenshot pack for Stitch

`docs/design/stitch/pack/` holds screenshots (clean, annotated, scroll slices, stitched long images, contact sheets) and a spec and ready-to-paste prompt for each of 25 screens, captured from the built app on simulated demo data. Start at [pack/INDEX.md](pack/INDEX.md); how to use it is in [pack/README.md](pack/README.md). Rebuild with `python tasks.py stitch-pack`. Core scope: no dark theme (the app has none), Tamil, empty, loading, error or offline states.
