# Paper Studio: verification of generated papers

Generated by `scripts/paper_studio.py evidence`. Do not edit by hand.

For each language layout, 200 pre-tests were generated from rules version 1 (half on `baseline_10`, half on `standard_10_5`, across six class profiles from past counts, intake answers and the standard paper), each with its post-test twin. Every pre-test and twin went through the independent verifier (`services/papers/verifier.py`: keys, wrong answers, coverage, discrimination, duplicates, twins), the string and glyph check, and a full render whose layout map was checked for overflow and overlap. A pair passes only if both papers pass every check. These are generated papers with made-up class profiles, not real classes.

| Layout | Pairs generated | Pairs that passed every check | Failed checks |
| --- | --- | --- | --- |
| English | 200 of 200 | 200 of 200 | none |
| Hindi | 200 of 200 | 200 of 200 | none |
| Tamil | 200 of 200 | 200 of 200 | none |
| English and Hindi | 200 of 200 | 200 of 200 | none |

Passing the automatic checks is not the same as approval of the wording: the Hindi and Tamil string packs are not yet reviewed by a reader of each language, so papers in those layouts wait in the review queue until a person approves them.
