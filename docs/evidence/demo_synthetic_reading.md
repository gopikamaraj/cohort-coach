## One demo run

The automated end-to-end run (`apps/pwa/e2e/demo.spec.ts`, all 12 steps, recorded AI answers) took 17 seconds on 2026-10-30. A person reading each screen takes longer; that has not been timed yet.

AI cost of one full demo run with nothing cached: $0.2402 over 7 distinct calls (c05_track_draft $0.2386, c07_checker $0.0010, c08_answer_reading $0.0004, c12_chat_classify $0.0002), from a run in record mode. Later runs reuse the cached sheet read and the cached first lesson.
