# Rejections that feed call 7

Reviewers reject AI content with one structured reason (wrong maths, culturally off, too complex
for the medium, tone issue, factually shaky). Each approved example is saved in `approved/` as a
small YAML file named `YYYY-MM-DD-NNN.yaml` and the latest few are included in call 7's prompt as
"rejected before, and why". Examples are reviewed content, never teacher text from rehearsals.

```yaml
reason: wrong_maths
language: en
text: "52 - 29 = 37, so the answer is 37."
```
